# AGENTS.md

This repo ships Genizah: one Agent Skill in the open SKILL.md format, at
`plugins/genizah/skills/genizah/SKILL.md`. Any agent that reads SKILL.md can use it.

When someone asks to free up disk space, clean their computer or find what is filling their
disk, follow that SKILL.md, including its first-time setup. It reads one system guide from
`references/` (macos.md, windows.md or linux.md) for commands and locations.

Never delete anything the skill does not allow, never use admin rights without asking, and
send personal files to the Trash or Recycle Bin rather than deleting them.
